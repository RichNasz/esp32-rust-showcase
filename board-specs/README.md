# board-specs/

AI-generated hardware specification files for ESP32 modules and development kits. All files in this directory are generated by the **esp32-board-spec-generator** skill from vendor datasheets, product pages, and schematics — never written by hand.

v1 **firmware** compiles only for ESP32-C6 (`esp32c6`). Required board: **ESP32-C6-DevKitC-1-N8**. Also supported: **Seeed XIAO ESP32-C6**. The catalog is those two boards. Do not add other SoCs. Chip ≠ board.

## Board Spec Contents

Each board spec file includes:

- **Module / SoC** — chip variant, revision, and certified RF module if applicable
- **Pin assignment table** — GPIO number → peripheral mapping (I2C, SPI, UART, PWM, ADC, USB)
- **Strapping and reserved pins** — boot-mode pins, JTAG, internal flash lines
- **Power supply rails** — 3.3 V regulator limits, LiPo charger presence, USB VBUS handling
- **Flash and PSRAM** — type, size, interface speed
- **Antenna** — PCB trace, IPEX/U.FL connector, ceramic, or integrated module antenna
- **USB console** — UART bridge (`espflash` on the UART-C port), USB Serial/JTAG, or USB CDC. There is no sdkconfig.
- **Special notes** — LED/button GPIOs, RTC GPIO 0–7 on C6, USB considerations
